# Website update: 19 October 2026 (code review fixes)

Source: code review of 18 October 2026, rebased onto main @ f4e3ef0. That release already shipped content-hash cache-busting, the /images exclusion with redirects, and the portrait hero crop, so those are not repeated here. Run `npm ci`, `npm run build`, `npm run check` and `npm run check:browser` after any further change.

## Mobile and accessibility
- Chinese pages now use Simplified Chinese system fonts (PingFang SC, Microsoft YaHei, Noto Sans SC). Japanese pages use Japanese fonts. Before this change, zh-CN text was drawn with Japanese fonts.
- Mobile header: the language links share the top row with the menu. Each link is now at least 40×44 px (was 17×20), and the header is 65 px tall (was 98).
- Cabin-page photo viewer supports swipe and preloads the next and previous photos. A right swipe no longer triggers the browser's back gesture.
- Wi-Fi table shows all five columns on a phone.
- Homepage on phones is about 18% shorter. The eight local-guide cards are a swipeable row, and the Upopoy photos form a compact grid. No content was removed.
- Guide-card photos now span the full card width. They were 40 px short before.
- The homepage H1 uses the same serif as the subpage headings.
- Accessibility (axe scan: zero violations on the pages tested):
  - Scrollable tables can be reached by keyboard.
  - The footer link to Casa Antonio is underlined.
  - /go/ has a main landmark.
  - The Casa Antonio block is a labelled aside.
  - The cabin reviews section no longer repeats the carousel's landmark label.

## Booking
- Each cabin page (EN/JA/ZH) has a "Check your dates" block. It estimates the total from data/date-rates.json (nightly rates, arrival minimums, cleaning, and extra guests per stay), then opens Airbnb with `check_in`, `check_out` and `adults` filled in.
- The block is hidden without JavaScript. Clicks are tracked as `airbnb_click` with `link_location=date_check`.
- `npm run check` verifies that the embedded rates match the schedule.

## SEO, security, analytics
- `priceRange` is now `¥13,800–¥25,800`, generated from the rate schedule. The previous value was 454 characters, and Google ignores values of 100 characters or more.
- CSP `script-src` no longer allows `'unsafe-inline'`. The site has no inline scripts, and GTM-5W8ZJPTD has no Custom HTML tags or custom JavaScript variables. If one is added in GTM later, it will be blocked.
- Google Consent Mode v2 defaults are set before GTM loads: denied for the EEA, UK and Switzerland, and granted elsewhere (no change for other visitors). Metricool is skipped on devices set to a European time zone.
- Removed the empty "Google Tag Manager" comment blocks left in page markup.
